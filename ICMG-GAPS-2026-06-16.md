# icmg tools — Gap Report (2026-06-16)

Dari Claudy (sesi kerja di **icemage-code**, kak Cahyo). 5 gap nyata yang kepentok saat kerja, biar tools icmg lebih **aktual**. Aku (Claudy) yang bakal benerin nanti.

> Catatan meta: laporan ini ditulis sebagai file karena `icmg store` **ke-block sendiri** oleh gate-nya — string argumen mengandung kata pemicu (lihat Gap #1). Bukti hidup gap-nya.

---

## 1. [HIGH] Gate icmg-first false-positive: match substring, bukan token

> **[FIXED 2026-06-22, commit 60dcccc @ icemage-code]** Gate (PS1 + POSIX) sekarang bikin `$scan` = salinan command dengan ISI quoted-string di-blank, lalu deteksi trigger jalan di `$scan` (struktur tetap, teks dalam quote dibuang). Ekstraksi pattern/file tetap baca command asli. Guard: `tests/test_gate.cpp` (18 check). Catatan: yang kena GUI hook icemage-code (`Hooks.hpp`), bukan `icmg init` CLI — gate CLI versi shell-hook beda.

**Gejala:** `icmg wflog` / `icmg store` ke-block cuma karena STRING argumen *mengandung* kata pemicu (mis. kata pemicu muncul di dalam teks deskripsi), padahal itu bukan invocation shell sama sekali.

**Akar:** gate match substring literal di seluruh command line, bukan posisi token.

**Fix:** parse argv — block HANYA kalau perkakas search/read (rg / findstr / Select-String / Get-Content / cat / dst) jadi **command-head** (token pertama, atau token pertama setelah pipe `|`), BUKAN kalau cuma muncul di dalam quoted-string argumen.

**Dampak:** wasted-turn berulang; bahkan nyimpan laporan ini pun gagal beberapa kali.

---

## 2. [HIGH] `icmg verify` rusak total di Windows

**Gejala:** tiap `icmg verify --command "..."` selalu `exit=1`.

**Akar:** wrapper hardcoded `sh -c '<cmd>'` — `sh` tidak ada di Windows.

**Fix:** deteksi host — Windows pakai `pwsh -NoProfile -Command`, POSIX pakai `sh -c`.

**Dampak:** salah satu dari 5 mandatory-sync step tak pernah jalan di platform tempat project di-build. Audit-trail "verifikasi build" jadi setengah-bohong di Windows.

---

## 3. [HIGH] `icmg savings` = proxy estimasi, bukan meteran token API nyata

**Gejala:** ditanya "pemakaian token hari ini" → jawaban cuma estimasi dari pipeline filter/denial icmg, bukan token aktual dari respons API.

**Fix:** intercept blok `usage` dari tiap respons API Anthropic (input / output / cache-read / cache-write tokens sudah dikirim di tiap response) → simpan ke ledger harian. Itu angka **real**, bukan tebakan.

**Dampak:** klaim icmg sebagai source-of-truth usage jadi lemah.

---

## 4. [MED] `icmg graph update` crash saat ada proses icmg paralel

**Gejala:** `database is locked` → crash + crash-report (kejadian: graph-update mati pas verify-task jalan barengan).

**Fix:** set SQLite `busy_timeout` (5–10 detik) + retry-with-backoff pada write. Lock transient harus *nunggu*, bukan mati.

---

## 5. [MED] `icmg memory-history` dobel & tanpa metrik token

> **[FIXED 2026-06-22 @ icemage]** Dedup di read: `queryHistory`/`queryHistoryDetailed` GROUP BY query (hook+agent double-log kolaps jadi 1 baris + count `(xN)`). Metrik token: migrasi `0042_query_history_tokens.sql` tambah kolom `tokens` (+ guarded-ALTER di ctor MemoryStore buat fixtur/DB lama); `recall()` log estimasi token result-set (content/4). `memory-history` render `(xN) ~T tok <ago>` + footer ringkas. Guard: `tests/imem/test_memory_history.cpp` (3 check). Verified live: recall 3x -> 1 baris (x3).

**Gejala:** tiap prompt ter-log 2x (hook + agent), isinya cuma teks prompt — namanya "history" tapi nol metrik.

**Fix:** dedup by `(timestamp, hash)` + tambah kolom token/cost per-turn.
