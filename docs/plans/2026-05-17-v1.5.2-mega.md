# v1.5.2 Plan — Python sidecar hardening + B:/ popup elimination

> **For Claude:** REQUIRED SUB-SKILL: Use the appropriate execution skill (`executing-plans` or `subagent-driven-development`).
> **Build gate:** Only build after explicit user approval ("ok build", "lanjut build", etc.).

**Goal:** Eliminate the recurring `B:/` Windows critical-error popup and stabilize the embedder Python sidecar so `icmg health` reports `embed=OK`.

**Architecture:** Two-pronged defense — belt-and-suspenders SetErrorMode in the Python sidecar (so even if Win32 inheritance ever fails, child still suppresses popups), plus stdout hardening to convert `OSError` into a graceful self-shutdown signal. Sidecar bootstrap becomes idempotent against transient HF cache failures.

**Tech Stack:** C++17 (parent spawn path), Python 3.10+ (sidecar), Win32 SetErrorMode via ctypes, sentence-transformers (ORT InferenceSession backend).

**Assumptions:**
- Popup source = Python sidecar OR descendant subprocesses spawned by HF/transformers stack. Assumes NOT a Claude Code hook bash script (those run under Claude, not icmg). Will NOT cover popups originated by Claude's own subprocess tree.
- Embedder OSError is on `sys.stdout.write` (parent pipe closed early / broken pipe). Assumes NOT a model-load OSError (separate path, already logged to stderr).
- v1.5.1 binary is the baseline; no need to re-fix shadow-upgrade pin / version drift.

---

## Risk Register

| Risk | Mitigation |
|---|---|
| ctypes import fails on stripped Python (e.g. embedded distributions) | Wrap in try/except; sidecar still works without SEM set, only the popup edge case remains. |
| Wrapping stdout breaks the JSON handshake | Wrapper preserves `line_buffering=True` semantics; emit on stdout goes through the same `print(..., flush=True)` path. |
| SetErrorMode-in-Python won't help if popup originated in transformers C extension before our wrapper runs | Place SEM call at line 1 of the file, before any imports. |

**Step 1 — Add failing test (smoke style):**

**Step 2 — Implement minimal change**

Insert at the very top of `embed/icmg_embedder.py`, BEFORE any `import io`/`import sys`/etc.:

```python
# v1.5.2: belt-and-suspenders — Windows child inherits parent SetErrorMode,
# but enforce locally too in case spawn path bypassed inheritance (e.g. a
# transformers/torch C extension forks an internal helper that re-launches
# without the inherited mode). SEM_FAILCRITICALERRORS suppresses the
# "B:/ — system cannot find drive" dialog.
import sys
if sys.platform == "win32":
    try:
        import ctypes
        SEM_FAILCRITICALERRORS = 0x0001
        SEM_NOOPENFILEERRORBOX = 0x8000
        ctypes.windll.kernel32.SetErrorMode(SEM_FAILCRITICALERRORS | SEM_NOOPENFILEERRORBOX)
    except Exception:
        pass  # graceful: popup may recur, but sidecar still runs
```

**Step 3 — Verify task:**
Run: `python embed/icmg_embedder.py < /dev/null` (Windows: `type nul | python embed\icmg_embedder.py`).
Expected: exits 0 with either `{"op":"ready",...}` (if sentence-transformers installed) or `{"error":"sentence-transformers missing"}` then exit 0.

**Step 4 — Commit**
```bash
git add embed/icmg_embedder.py
git commit -m "fix(v1.5.2 T1): set SEM_FAILCRITICALERRORS in Python sidecar"
```

**Step 1 — Failing test:**
Manually close parent's read end, then call `emit()` once. Expected: process exits with code 0 (graceful), not Python traceback.

**Step 2 — Implement minimal change**

Replace the existing `emit()` function (around line 43-46):

```python
def emit(obj):
    """Write one JSON line to stdout. Graceful on broken pipe (parent died)."""
    try:
        json.dump(obj, sys.stdout, ensure_ascii=False)
        sys.stdout.write("\n")
        sys.stdout.flush()
    except (OSError, BrokenPipeError, ValueError):
        # Parent closed pipe. No use staying alive.
        try:
            sys.stderr.write("icmg-embedder: parent pipe closed, exiting\n")
        except Exception:
            pass
        sys.exit(0)
```

**Step 3 — Verify:**
Run: `python embed/icmg_embedder.py < /dev/null | true` (close stdout fast).
Expected: exits 0 silently, no Python traceback in stderr.

**Step 4 — Commit:**
```bash
git add embed/icmg_embedder.py
git commit -m "fix(v1.5.2 T2): graceful OSError handling in embedder stdout"
```
