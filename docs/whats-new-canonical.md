# Whats New README source of truth

CANONICAL "What's New" list for public README.md (max 5 entries, newest first). Updated for v2.14.0.

- **v2.14.0** — **Token-efficiency arsenal: seven new levers to cut recurring spend.** (1) `icmg run --nano` — symbol-only compression: build/test/lint diagnostics collapse to one dense `file:kind:code:line` per entry (gcc/clang/rustc + MSVC), ~95% on repeat builds. (2) `icmg run --gist` — one-line domain-aware TL;DR of command output (`12 passed, 3 failed. first fail: user.rs:45`), sub-ms, no LLM. (3) `icmg learn` — cross-session learning: mines the persistent `commands` table to flag consistently-noisy commands and recommend a tighter mode. (4) `ICMG_AUTO_ROUTE=1` — turns that advice into action: `icmg run` auto-applies `--nano`/`--gist` to learned-noisy commands (opt-in). (5) `icmg transcript cost` — re-send amplification analysis: an entry at position *i* of *N* is paid for *(N−i)* times; ranks the hotspots to compact first. (6) `icmg mcp audit` — tool-schema diet: per-turn token cost of every MCP tool, flags oversized ones. (7) Recall tier tie-breaker (opt-in `ICMG_RECALL_TIER_BOOST`) — hot/warm/cold breaks near-equal scores as a stable tie-breaker, provably no regression. **+34 tests, ctest 100% (Windows).**
- **v2.13.2** — **Fix: err126 root cause on Windows Server (clock_cast → icu.dll).** `std::chrono::clock_cast` pulled in `icu.dll`, absent on stock Windows Server 2019; two call sites (`bundle_cmd`, `graph_cmd`) now use direct epoch arithmetic in `file_time.hpp`. Added a throw-site diagnostic and a `doctor` write-probe for faster triage. 1331 tests ✓.
- **v2.13.1** — **Fix: err126 recurrence on Windows Server despite the v2.13.0 Vulkan gate.** The gate checked only that `HKLM\...\Khronos\Vulkan\Drivers` had ≥1 registry value, but a stale GPU driver leaves the value behind after its manifest is gone — false-positive, `vkCreateInstance` still crashed err126. Two-layer fix: manifest-on-disk verification (`vulkanIcdPresent()` requires ≥1 manifest to actually exist, pure unit-tested core) + error boundary (`llama_backend_init()` try/catch degrades to "LLM unavailable, command continues"). Workaround without upgrade: `ICMG_GGML_NO_VULKAN=1`. 2166/2166 tests (+4).
- **v2.13.0** — **WASM language extractors + host-caps: teach icmg a new language by dropping a `.wasm`, no rebuild.** extractor-v1 ABI (icmg_alloc/icmg_extract), JSON output maps 1:1 to ExtractResult, auto-consulted on graph scan, priority>0 overrides built-ins. `icmg skill wasm test`. Host-caps: optional `icmg.log(ptr,len)` import via wasmtime linker, backward-compatible. 2162/2162 ctest (+30).
- **v2.12.0** — icmg find Unicode crash fix (err 1113, issue #221, pathU8), build.ps1 auto-installs live binary (rename→copy→kill→cleanup), migration 0046 embedded parity.
