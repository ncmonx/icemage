# v1.51.0 — NL rule/skill management + autoDetectRule TDD extraction

**Status:** approved 2026-05-26
**Branch:** `release/v1.51.0`
**Ship policy:** Win-only

## Scope

1. **CLI skill CRUD** — `icmg skill add/remove/edit` writes/deletes `.md` in `~/.icmg/skills/` + auto-reindex via `skill index --force`.
2. **`src/cli/auto_rule.hpp`** — header-only pure module. Houses:
   - `detectNL(line) → NLDetectResult` (replaces inline `autoDetectRule` regex+extract).
   - Injectable savers (`RuleSaver`, `RuleRemover`, `SkillSaver`, `SkillRemover`) for unit tests.
   - Fuzzy resolver `fuzzyFindRule(query, threshold)`.
3. **NL detect manage ops in chat REPL** — prefix-anchored ID+EN triggers, evaluated in specific→general order.
4. **Fuzzy rule/skill name resolver** — inline lightweight BM25 (token overlap × idf / √len).
5. **TDD tests** — `tests/cli/test_auto_rule.cpp` (14 unit) + `tests/cli/test_skill_crud.cpp` (2 integration).

## Non-goals

- Skill content edit via deep diff (full-replace only).
- Multi-target batch ops in one msg (`hapus rule X dan Y`).
- Voice-style ambiguous fuzzy (`ilangin yg soal emoji`).
- Linux ship (Win-only policy active).

## Architecture

```
chat_cmd.cpp REPL
  └─ on user msg → detectNL(line)
        ├─ NLAction::ADD_RULE     → ruleSaver(name, content)
        ├─ NLAction::REMOVE_RULE  → fuzzyFindRule → ruleDisabler(id)   # soft, reversible
        ├─ NLAction::EDIT_RULE    → fuzzyFindRule → ruleSaver(name, body, update=true)
        ├─ NLAction::ADD_SKILL    → skillSaver(name, body)
        ├─ NLAction::REMOVE_SKILL → fuzzyFindSkill → skillRemover(name)
        └─ NLAction::NONE         → fall through LLM
```

**Trigger eval order (specific → general):**
REMOVE_RULE → EDIT_RULE → ADD_SKILL → REMOVE_SKILL → ADD_RULE (last; catches existing `selalu`/`ingat ya` triggers).

## Interface (`src/cli/auto_rule.hpp`)

```cpp
namespace icmg::cli {

enum class NLAction {
    NONE, ADD_RULE, REMOVE_RULE, EDIT_RULE,
    ADD_SKILL, REMOVE_SKILL
};

struct NLDetectResult {
    NLAction action = NLAction::NONE;
    std::string target_name;   // for remove/edit — fuzzy lookup key
    std::string content;       // for add/edit — body
};

// Pure: regex + extract. No subprocess, no IO. Cap size 8..500.
// Returns NONE if env ICMG_NO_AUTO_RULE=1.
NLDetectResult detectNL(const std::string& line);

struct RuleRecord { std::string id; std::string name; std::string content; };

// Lightweight BM25-ish: tok-overlap × idf / √len.
// Returns best match if score >= threshold, else empty.
struct FuzzyMatch { std::string id; std::string name; double score; };
std::vector<FuzzyMatch> fuzzyFind(
    const std::string& query,
    const std::vector<RuleRecord>& corpus,
    double threshold = 0.5);

// Caller-supplied side-effect adapters.
using RuleSaver    = std::function<int(const std::string& name, const std::string& body, bool update)>;
using RuleDisabler = std::function<int(const std::string& id)>;
using SkillSaver   = std::function<int(const std::string& name, const std::string& body, bool update)>;
using SkillRemover = std::function<int(const std::string& name)>;
using RuleLister   = std::function<std::vector<RuleRecord>()>;
using SkillLister  = std::function<std::vector<RuleRecord>()>;  // same shape

struct NLAdapters {
    RuleSaver    rule_save;
    RuleDisabler rule_disable;
    RuleLister   rule_list;
    SkillSaver   skill_save;
    SkillRemover skill_remove;
    SkillLister  skill_list;
};

// Orchestrator: detect + dispatch via adapters. Returns ack string for chat,
// empty if NONE. Logs to stderr on failure but never throws.
std::string handleNL(const std::string& line, const NLAdapters& a);

} // namespace icmg::cli
```

## Trigger patterns

Lowercase first 80 chars; prefix-anchored (`rfind(t, 0) == 0`).

| Action | ID triggers | EN triggers |
|---|---|---|
| REMOVE_RULE | `hapus rule `, `buang rule `, `ilangin rule ` | `remove rule `, `delete rule `, `drop rule ` |
| EDIT_RULE | `ubah rule `, `ganti rule `, `update rule ` | `edit rule `, `change rule ` |
| ADD_SKILL | `tambah skill `, `buat skill ` | `add skill `, `create skill ` |
| REMOVE_SKILL | `hapus skill `, `buang skill ` | `remove skill `, `delete skill ` |
| ADD_RULE | `ingat ya`, `tolong ingat`, `aturannya `, `aturan baru`, `jangan pernah `, `selalu `, `harus selalu`, `mulai sekarang`, `sejak sekarang`, `peraturan baru:` | `remember `, `from now on`, `please always`, `please never`, `always `, `never `, `rule:` |

**Parsing:**
- REMOVE_*: token after prefix = `target_name` (rest-of-line stripped, trailing punct removed).
- EDIT_RULE: `<name> jadi <body>` or `<name> to <body>` or `<name> => <body>`. Split on first separator.
- ADD_SKILL: `<name> <body>` (first word = name, rest = body). If only name → body empty → fail-soft ack `(skill name only — type body next or use slash)`.

## CLI: `icmg skill add/remove/edit`

```
icmg skill add <name> <content> [--update]
  → write ~/.icmg/skills/<sanitize(name)>.md (content = body)
  → icmg skill index --dir ~/.icmg/skills --force
  → exit 0 + stdout: "skill saved: <name>"

icmg skill remove <name>
  → resolve via fuzzy on skill list (threshold 0.5)
  → delete ~/.icmg/skills/<file>.md
  → DELETE FROM context_nodes WHERE tier='skill' AND name=?
  → exit 0 + stdout: "skill removed: <name>"

icmg skill edit <name> <new-content>
  → equiv to add --update
```

**Sanitization:** `[a-z0-9._-]+` (lowercase, replace others with `-`, collapse dashes).

**New dir:** `~/.icmg/skills/` created on first add. Cohabits with existing `~/.icmg/llm/`, etc.

## Error handling

| Case | Behavior |
|---|---|
| Trigger match + empty target after parse | Inline ack `(NL parse failed — use \rule slash)`, fall through LLM. |
| Fuzzy 0 matches | `(no rule matching "X" — \rules to list)`. No action. |
| Fuzzy ≥2 tied (score within 0.05) | `(ambiguous: <id1>, <id2> — type "hapus rule <id>" or use \unrule)`. No action. |
| Fuzzy below threshold (0.5) | Treat as 0 matches. |
| Subprocess fail (exit ≠ 0) | Stderr `(action failed: <stderr>)`, fall through LLM. Never crash REPL. |
| `ICMG_NO_AUTO_RULE=1` | `detectNL` returns NONE immediately. |
| Size <8 or >500 chars | NONE. |
| Mid-sentence trigger | NONE (prefix-anchored only). |

**Safety:** NL remove → `icmg rule disable` (soft, reversible). Hard `remove` reserved for explicit `\unrule` slash.

## Adversarial failure modes (resolved)

1. **CRITICAL → mitigated:** `"selalu hapus rule X dari memory"` would match ADD_RULE first under naive order. **Fix:** eval REMOVE/EDIT triggers before ADD_RULE.
2. **CRITICAL → mitigated:** Silent fuzzy-top1 destructive delete. **Fix:** NL path uses `disable` (soft); threshold ≥0.5; ambiguous → list, no action.
3. **MINOR (documented non-goal):** EDIT separator collision (`"foo jadi bar jadi baz"`) → split on first occurrence only.
4. **MINOR (documented non-goal):** `~/.icmg/skills/` collide with user's custom skill dir → user passes `--dir` to `skill index`.
