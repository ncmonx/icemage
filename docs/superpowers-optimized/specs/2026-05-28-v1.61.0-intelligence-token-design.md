**Status:** draft 2026-05-28

**Theme:** smarter routing/matching/mining + deeper token cuts.

## Scope (7 features; F9 fine-tune moonshot deferred)

### T2 Intelligence

**F6 — LLM-augmented router (~4h)**
Optional Dolphin-8B classification when the regex router is low-confidence.
Regex stays the hot-path default (sub-ms); on ambiguous prompts (confidence
< threshold) AND `ICMG_LLM_ROUTER=1`, ask the warm LLM LOCAL/CLOUD/CACHE.
**Files:** `src/cli/router.cpp` (classifyPrompt fallback), reuse warm-loop.
**Risk:** LLM latency on hot path → gate behind low-confidence + env; cache result.

**F7 — Embedding-based fuzzy (~3h)**
Rule/skill fuzzy match upgraded from token-overlap to ONNX cosine similarity
so "hapus rule about emoji" matches "no-emoji rule" cross-phrasing.
**Files:** `src/cli/auto_rule.hpp` fuzzyFind → embedding path when ONNX avail,
token-overlap fallback. Reuse `src/embed/`.
**Risk:** embedding latency per match → cache rule embeddings; fallback if no ONNX.

**F8 — Auto-pattern mining (~5h)**
`icmg mine` scans session-log → LLM proposes candidate rules/skills/reminders.
Output is SUGGESTIONS only (never auto-applies). User confirms.
**Files:** `src/cli/commands/mine_cmd.cpp` (new). Reuse warm LLM + session-log.
**Risk:** LLM hallucination → suggestions gated behind explicit review; dedup vs existing rules.

**F10 — Confidence scoring (~3h)**
Router + fuzzy + recall emit a confidence score; low-confidence operations
print a `[low-confidence]` hint. Pure logic over existing scores.
**Files:** `src/cli/router.{hpp,cpp}` (expose score), recall/fuzzy annotate.
**Risk:** miscalibrated threshold → conservative default, env-tunable.

### T3 Token

**F12 — `icmg gist <file/url> (~4h)`**
LLM TL;DR of a large file/URL before Claude reads it. `icmg gist <path>`
returns a dense summary (warm LLM). Cache by file hash.
**Files:** `src/cli/commands/gist_cmd.cpp` (new). Reuse warm LLM + fetch.
**Risk:** summary loses critical detail → always note "summary; use icmg context for full".

**F14 — Differential context (~5h)**
`icmg pack`/context emit only the DIFF vs the previously-sent bundle in the
same session, not the full bundle. Track last-sent hash per session.
**Files:** `src/cli/pack_delta.*` (exists — extend), session-state hash.
**Cut:** 40-60% on repeat sessions.
**Risk:** AI missing baseline → only diff when baseline confirmed sent this session; full on first.

**F15 — Semantic dedup memory (~4h)**
Memory store dedup upgraded from FNV-128 byte-exact to embedding cosine
(near-duplicate "fixed X bug" / "X bug resolved" collapse).
**Files:** `src/imem/` store insert path; cosine threshold; FNV fallback.
**Risk:** over-merge distinct memories → high cosine threshold (0.95+); keep both on doubt.

## Failure modes (adversarial)

1. **LLM on hot path (F6/F7) adds latency** → all LLM/embedding paths are
   opt-in or low-confidence-gated; regex/token-overlap remains default;
   results cached.
2. **F8 mining hallucinates bad rules** → suggestions only, never auto-apply;
   dedup against existing rules; user confirms each.
3. **F12 gist drops critical detail** → output always tagged "summary —
   icmg context for full"; cache keyed by file hash (re-summarise on change).
4. **F14 diff-context starves AI of baseline** → diff only after baseline
   confirmed sent this session; first request always full; session-state hash.
5. **F15 over-merges distinct memories** → cosine threshold ≥0.95; on doubt
   keep both; FNV exact-dup still collapses first (cheap).
