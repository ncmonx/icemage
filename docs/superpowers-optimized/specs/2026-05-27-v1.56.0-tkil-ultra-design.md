# v1.56.0 mega — Tkil Ultra + daemon + strict-enforce

**Status:** draft 2026-05-27
**Branch:** `release/v1.56.0` (forked from v1.55.0 HEAD `93cee47f16`)
**Ship policy:** Win-only mega, multi-session exec.
**Theme:** absolute token-shred — every cmd output stripped to essentials.

## Scope (4 sub-features)

### T1 — Tkil Ultra (~18h, centerpiece)

Stack three additional passes on top of the existing per-cmd `BaseFilter`:

```
raw stdout ─► [stage1 per-cmd filter (existing)]
            ─► [stage2 dedup pass]
            ─► [stage3 pattern collapse]
            ─► [stage4 outcome-only] (when applicable)
            ─► [stage5 session glossary]
            ─► AI sees ~95% smaller output
```

**Stage 2 — Dedup pass.** Adjacent identical/near-identical lines collapse to `<line> (×N)`. Near-identical = Levenshtein ≤ 3 or shared prefix ≥ 80%. Streaming O(n) — single-pass with 1-line lookback buffer.

**Stage 3 — Pattern collapse.** Per-cmd-type "verbose pattern" library:
- `npm install`: collapse `added N packages in M ms` family
- `gh api`: collapse JSON key/value pairs to `{N keys}`
- `cmake --build`: collapse `[i/n] Building ...` to `[built N objects]`
- `git push`: collapse `remote: ...` banner lines
- Each profile keyed by Detector cmd-type.

**Stage 4 — Outcome-only mode.** For "fire-and-forget" commands the AI only needs the final result. Allowlist:
- `gh release create/upload/edit` → last URL + exit code
- `git push` → branch line + commit-range
- `curl -sS -o file` → exit + bytes written
- `cmake --build` → final `[n/n] Linking ...` + exit
Trigger: cmd matches allowlist OR `--ultra` flag explicit.

**Stage 5 — Session glossary.** Same gimmick as F11 persona-inject. Common phrases (frequency ≥ 3 within session) get mapped to short tokens:
- `[icmg context] stale (file mtime ...s > node.updated_at) — rescanning...` → `$S1`
- `[icmg shrink: build log] X error(s), Y warning(s) in Z lines` → `$S2`
- Dict stored at `~/.icmg/tkil-session-glossary-<sid>.json`, cleared on session end
- `icmg expand <token>` returns full phrase
- Auto-built — first appearance kept verbatim, subsequent → token

**Activation:**
```
icmg run --ultra <cmd>              # explicit per-call
ICMG_TKIL_ULTRA=1 ...               # session-wide env
icmg run <cmd>                      # auto when output > 5KB AND dup-ratio > 0.4
```

Opt-in default v1.56. Make default v1.57 once telemetry shows no false-positive error suppression.

**Files:**
- `src/tkil/dedup_pass.{hpp,cpp}` — Stage 2
- `src/tkil/pattern_profiles/*.cpp` — Stage 3 (per cmd-type)
- `src/tkil/outcome_extractor.{hpp,cpp}` — Stage 4
- `src/tkil/session_glossary.{hpp,cpp}` — Stage 5
- `src/tkil/filter.cpp` — wire pipeline + `--ultra` flag

### T2 — G3 everything-wrapper (~3h)

Extend bash auto-rewrite hook (`.claude/hooks/icmg-bash-rewrite.sh`) to redirect MORE native commands through `icmg run`. Currently covers grep, node, cargo, pytest. Add: tsc, eslint, ruff, black, ruby, php, mvn, gradle, go, deno, bun, prettier. Each gets `icmg run <cmd>` so Tkil Ultra applies.

**File:** `.claude/hooks/icmg-bash-rewrite.sh` (also embed in `init_cmd.cpp`).

### T3 — F1 long-lived `icmg-server` daemon (~6h)

Replace per-call `icmg.exe` spawn (≈30 ms cold start × ~500 calls/session = 15s wasted) with a single warm daemon that holds:
- Loaded Config singleton + open DBs
- Tkil session glossary (T1 Stage 5) cross-call
- Memory store handle (no per-call SQLite open/close)
- Warm-loop daemon already (v1.52) — extend protocol

Named pipe `\\.\pipe\icmg-server`. JSON-line RPC:
```
{"cmd":"context","args":["<file>"]}   → {"ok":true,"out":"<filtered output>"}
{"cmd":"run","args":["grep","-r","foo","."]}  → {"ok":true,"out":"..."}
```

Thin `icmg.exe` shim auto-connects to daemon (falls back to in-process when daemon absent). Daemon launches lazily on first `icmg` call OR via `icmg server --start`.

**Win:** ~30ms × N saved + Tkil session glossary actually works across calls (was per-process, lost on exit).

**Files:**
- `src/server/icmg_server.{hpp,cpp}` — daemon loop
- `src/server/rpc_protocol.{hpp,cpp}` — JSON-line schema
- `src/cli/dispatcher.cpp` — auto-connect client path
- `src/cli/commands/server_cmd.cpp` — `icmg server --start/--stop/--status`

### T4 — G2 strict-enforce (~2h)

Currently Rule #13 "icmg-FIRST" is soft — hook emits a redirect message but doesn't BLOCK. Strict mode (already partial via `icmg strict`) gets:
- Hard-block native `grep`, `cat`, `find` etc. via PreToolUse Bash hook returning `permissionDecision: "deny"` with redirect text
- Stop hook lint: emit warning if session had >5 native-tool calls that have icmg equivalents
- Per-tool counter telemetry in `~/.icmg/strict-violations.txt`

**Files:**
- `.claude/hooks/icmg-strict-enforce.sh` (new)
- `init_cmd.cpp` — embed + UserPromptSubmit/PreToolUse entry
- `src/cli/commands/strict_cmd.cpp` — add `--report` showing violation stats

## Failure modes (adversarial)

1. **Stage 2 dedup over-collapse.** Real distinct errors that look adjacent (e.g., `LNK2001: foo`, `LNK2001: bar`) → wrongly merged. Mitigation: error-pattern allowlist always-verbatim (regex: `\b(error|fail|FATAL|LNK\d{4}|RC\d{4}|C\d{4}):`). Per-profile regression test.
2. **Stage 5 glossary drift between calls.** If daemon (T3) restarts mid-session, glossary lost → AI sees `$S1` with no expansion. Mitigation: include glossary version in `additionalContext`. On client-side mismatch, request `icmg expand $S1` re-fetches.
3. **T3 daemon dies, client falls back, slow.** Daemon crash → 500 calls × cold spawn = re-pay 15s loss. Mitigation: client emits `[icmg] daemon-down — restart with 'icmg server --start'` once per session.
4. **T4 strict-enforce blocks legit use.** Hard-block on `cat` for a 5-line file user wrote themselves = annoying. Mitigation: `RAW=1` always escapes; user files >1KB exempt from hint (only icmg-eligible patterns blocked).

## Ship validation

- `icmg --ultra run npm install <heavy-pkg>` → output < 200 bytes (vs ~4KB raw)
- Session glossary hit rate ≥ 0.4 after 30 calls
- Daemon round-trip < 5ms p99
- Strict-enforce blocks `cat /etc/hosts` (icmg-eligible) but allows `cat my-script.sh` (user file)
