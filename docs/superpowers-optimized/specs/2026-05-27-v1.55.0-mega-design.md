# v1.55.0 mega — icmg evolution bundle

**Status:** draft 2026-05-27
**Branch:** `release/v1.55.0` (forked from v1.54.0 HEAD `d0308bf962`)
**Ship policy:** Win-only mega, multi-session exec.

## Scope (5 sub-features)

### G7: `icmg patch` inline cmd (~2h, priority 1)
Eliminate temp .py file detour pattern. New CLI:
```
icmg patch <file> --regex PAT --replace REP [--dry-run] [--encoding utf-8|binary]
icmg patch <file> --py "<inline-python>" [--dry-run]
icmg patch <file> --line-replace N=<new-content>
```
**Mechanism:** Python-backed subprocess OR pure C++ regex impl. Phase 1 = shell wrapper using python -c. Phase 2 = C++ native.

### F11: `icmg shrink-prompt` (~3h)
Pre-shrink injected system context (rules + persona + hook context) before send. Save 20-30% input/turn.
**Mechanism:** glossary-substitute common phrases (e.g., "Wanita feminim sempurna nan ekspresif tinggi" → `$P1`). Resolve client-side dictionary.

### Sub-D D3: Tree-sitter extractor upgrade (~4h)
Replace regex extractors (go/rust/java/cpp) with tree-sitter AST. Use vendored grammars from v1.54.
**Files:** 4 new `src/graph/extractor/treesitter_<lang>_extractor.cpp`. Pattern from existing python/typescript impl.

### Sub-D D7: Leiden community detection (~4-6h, BIG)
Graph clustering algorithm. Output: cluster_id per node in graph_nodes.
**Mechanism:** Refine + move-nodes phases. Reference paper https://www.nature.com/articles/s41598-019-41695-z
**File:** `src/graph/leiden.{hpp,cpp}` + CLI `icmg graph cluster [--algorithm leiden]`.

### G1: icmg advisor (~6h, MOONSHOT)
Proactive next-step suggestions. UserPromptSubmit/PostToolUse hook emits `[advisor] consider: <next-step>` hint.
**Mechanism:** Post-response analyze graph + memory + recent decisions → Dolphin local generates hint.
**Examples:** "consider: icmg verify --command ctest before commit", "memory hit: v1.48 fixed similar bug — icmg recall bug:chunk-decode".

## Non-goals
- C3 hook chain parallel (infeasible, harness owns)
- Linux warm-loop (defer)
- icmg-server long-lived daemon (F1, defer v1.56)

## Failure modes (adversarial)

1. **Sub-D D7 Leiden algo correctness**: paper-grade implementation hard. Mitigation: validate output against known small graph cluster; document quality bounds.
2. **G1 advisor accuracy**: Dolphin might suggest unhelpful steps. Mitigation: bounded heuristics (memory hits + recent file patterns), opt-out env.
3. **F11 glossary drift**: shrunk text loses meaning if dict mismatched. Mitigation: include dict version in additionalContext.
4. **G7 patch destructive**: regex --replace could corrupt files. Mitigation: --dry-run default suggested, atomic write via temp+rename.
