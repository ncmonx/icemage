## 1. v1.64 — C++ Perf Quick-Wins (low effort, high ROI, all deterministic-testable)

Theme: build + runtime + startup speed. No behaviour change; all measurable.

### T1 — Branchless BM25 (~30 min)
`src/imem/scorer.cpp` hot path. Replace branch with arithmetic select:
```cpp
float score = (term_freq > 0) ? idf * num / den : 0.0f;
```
**Test:** existing scorer tests must stay green (identical results); add a
parity test (old vs new formula on fixtures → equal within 1e-6).

### T2 — AOT prepared-statement cache (~2-4 h)
`src/core/db.cpp`: `StmtCache` keyed by SQL text → reuse `sqlite3_stmt*`,
`sqlite3_reset` between uses. Finalize all on Db close.
**Risk:** stmt lifetime vs Db lifetime → cache owned by Db, cleared in dtor.
Thread-safety: guard with the existing FULLMUTEX or a mutex.
**Test:** repeated query returns same rows; cache hit count increments;
no leak (finalize on close); concurrent access safe.

### T3 — SQLite compile-time pragmas (~1 h)
`CMakeLists.txt` sqlite3 target: `SQLITE_DEFAULT_MEMSTATUS=0`,
`SQLITE_OMIT_DEPRECATED`, `SQLITE_OMIT_PROGRESS_CALLBACK`,
`SQLITE_MAX_EXPR_DEPTH=0`, `SQLITE_ENABLE_MEMSYS5`.
**Test:** full ctest green (no behaviour regression); cold-start smoke.

### T4 — Lazy-init MCP tools (~4-8 h)
33 MCP tools register factories at static init. Defer construction until a
tool is first invoked (registry stores factory, builds on demand — already
the pattern; verify nothing eagerly constructs heavy state at register).
**Test:** all MCP tools still resolvable; `--mcp-server` lists 33; first
call constructs + works; startup-time smoke shows improvement.

**Ship gate:** full ctest green + before/after timing note in release.

## 2. v1.65 — Security Hardening (5 audit holes)

### S1 — Path traversal normalization (~3 h)
Every file-path input (context, gist, copy, import) → canonicalize +
reject escapes outside allowed roots. Reuse `core::path_utils` canonicalize;
add `isWithinAllowed(path)` guard at command entry.
**Test:** `../../etc/passwd` style inputs rejected; legit relative + abs
paths still work; symlink escape blocked.

### S2 — Daemon IPC auth (~3 h)
`icmg-server` pipe currently unauthenticated. Add a per-start token written
to `~/.icmg/server.token` (0600 / owner-ACL); client must present it in the
RPC handshake. Reject on mismatch.
**Test:** request with correct token served; wrong/absent token rejected;
token file ACL owner-only.

### S3 — Secret-scanner filesystem mode (~3 h)
Current scanner is memory-only. Add `icmg scan --fs <dir>` walking files for
secret patterns (reuse existing pattern set), skipping .git/build/binaries.
**Test:** seeded fake secret in a temp file detected; binary/large files
skipped; clean dir → no findings.

### Defer to v1.66+ (heavier, lower urgency)
- Encryption-at-rest (SQLCipher) — build-system + key-mgmt heavy.
- Rate limiting MCP — needs per-session counters + policy.

**Ship gate:** each fix has a negative test (attack rejected) + positive
test (legit use unaffected).

  headline sync (gist + README + repo desc) if ctest count changes.

  `scripts\msvc-build-test.bat` (icmg_test, Release).
