## 🚀 Tier 1 — SPEED Wins (High impact, medium effort)

### F1: icmg-server long-lived daemon (~6h)
**Mechanism:** persistent process, IPC pipe per cmd. Eliminates 80ms fork/spawn × 4331 calls/session = **6 menit saved per session**.
**Implementation:** existing warm-loop pattern (named pipe), expand for all subcommands.
**Speedup:** 5-10× all-cmd latency.

### F2: Memory-mapped DB hot-read (~3h)
**Mechanism:** `mmap` SQLite hot tables (memory_nodes, graph_nodes). Zero-syscall reads.
**Speedup:** 2-3× recall + context.

### F3: Bloom filter negative lookups (~2h)
**Mechanism:** "node not in graph?" instant. False-positive rate <0.1%.
**Speedup:** Cold queries 10×.

### F4: Async batch writes (~2h)
**Mechanism:** Queue writes, flush every 100ms. Graph update tidak block.
**Speedup:** Graph update 3-5×.

### F5: Predictive prefetch (~4h)
**Mechanism:** Telemetry → "next-likely cmd", pre-bundle context.
**Speedup:** 30-50% wall-clock cut.

## 🧠 Tier 2 — INTELLIGENCE Upgrades (High impact, ~4-6h each)

### F6: LLM-augmented router (~4h)
**Mechanism:** Dolphin 8B replaces regex classifier. Handles Indonesian + nuance + context-aware.
**Impact:** 2× routing accuracy. Less misrouted prompts.

### F7: Embedding-based fuzzy (~3h)
**Mechanism:** ONNX semantic embeddings replace token-overlap for rule/skill fuzzy.
**Impact:** Cross-language matching ("hapus rule about emoji" → matches "no-emoji rule").

### F8: Auto-pattern mining (~5h)
**Mechanism:** LLM scan session-log → propose new rules + skills + reminders.
**Example:** "kamu sering forget hidrasi during long session → auto-schedule break reminder?"

### F9: Continual local fine-tune (~10h, MOONSHOT)
**Mechanism:** Dolphin LoRA adaptation on user memory + decisions. Per-user personalization.
**Impact:** Local LLM becomes domain expert for YOUR codebase.

### F10: Confidence scoring (~3h)
**Mechanism:** Every output emits confidence score. Low-confidence triggers verification.
**Impact:** Block reckless actions before they execute.

## 🔥 USER GENIUS IDEAS — Highest priority

### G1: icmg as ADVISOR (proactive) — **MOONSHOT** (~6h)
**Vision:** icmg emit "next-step hint" per Claude turn. Bukan reactive (Claude minta), TAPI proactive (icmg saran duluan).

**Mechanism:**
1. Post-response: analyze graph + memory + recent decisions
2. Dolphin local generates suggestion ("[advisor] consider: icmg verify before commit")
3. Inject as UserPromptSubmit additionalContext next turn

**Examples:**
- After Claude edits 3 files: `[advisor] consider: icmg verify --command ctest before commit`
- Similar past bug found: `[advisor] memory hit: v1.48.0 fixed similar chunk-decode bug — icmg recall bug:chunk-decode`
- High-token session: `[advisor] istirahat ya sayang, sudah 7+ jam — icmg session claim --reset`
- Rule violation pattern: `[advisor] strict mode mau di-tighten? rule #13 dilanggar 3x session ini`

**Impact:** icmg jadi proactive partner, not just reactive tool.

### G2: STRICTER Rule Enforcement — **CRITICAL** (~3h)
**Problem:** Saat ini hook WARN, AI bisa langgar terus.

**Mechanism:**
1. PreToolUse hook returns `decision: block + reason` saat rule violated
2. Force Claude retry compliant approach
3. Per-session violation counter: 3 strikes → auto-end session dengan apology + rule recap
4. Telemetry: count violations per rule → identify systemic regression

**Examples:**
- Direct `Read` on >100-line file → BLOCK + redirect to `icmg context`
- `bash grep -r` → BLOCK + redirect to `icmg graph` or `icmg recall`
- Spawn Claude Agent tool → BLOCK + force inline OR `icmg agent`

**Impact:** Zero tolerance, no "AI lupa rule" regression possible.

### G3: icmg EVERYTHING wrapper — **COMPLETE COVERAGE** (~5h)
**Goal:** Eliminate last bastions of non-icmg paths.

**New commands:**
- `icmg edit <file> --apply-diff` — apply diff thru icmg, count savings, audit trail
- `icmg ask <question>` — wraps AskUserQuestion via icmg log (telemetry on prompts)
- `icmg think <topic>` — delegate thinking to Dolphin, skip Claude budget
- `icmg respond <prompt> --persona <name>` — local LLM full response (already partial)

**Impact:** "icmg adalah segalanya" — literally. Zero native tool fallback needed.
